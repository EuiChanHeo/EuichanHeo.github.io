Guide-Dog Robot

Mobility intelligence for a guide robot for the visually impaired

Mobility intelligence technology for a guide robot for the visually impaired. Designed and built the strain-gauge and FSR-sensor-based harness system used for interaction between the quadruped guide robot and its handler.

(Kim et al., 2024)
